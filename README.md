# Classroom Challenge

Motor web reutilizable para actividades de repaso competitivo y práctica individual.

## V1
- Modo competencia y práctica.
- Competencia diseñada para **equipos de 2–3 estudiantes**, hasta **12 equipos** en una clase de 35.
- Banco de preguntas separado del motor en JSON.
- Puntuación por acierto y velocidad, rachas y preguntas ×2.
- Resultado global y por categoría.
- Primer banco: **Centro de Procesamiento de Datos**.

## Estructura
```
index.html
css/styles.css
js/app.js
js/game.js
js/scoring.js
quizzes/cpd.json
```
